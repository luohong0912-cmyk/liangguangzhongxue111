GitHub Pages 上传步骤

1. 打开 GitHub，新建仓库。
   建议仓库名：liangguangzhongxue111

2. 进入仓库，点 Add file -> Upload files。

3. 解压 github-pages-class-directory.zip，把里面的 index.html、README.md 和 txt 验证文件上传。

4. 点 Commit changes。

5. 进入仓库 Settings -> Pages。

6. Source 选择 Deploy from a branch。

7. Branch 选择 main，文件夹选择 /root，然后 Save。

8. 等 1-3 分钟，GitHub 会给一个网址，格式类似：
   https://你的GitHub用户名.github.io/liangguangzhongxue111/

重要：
- GitHub Pages 只能放网页，不能直接放数据库后台。
- 这个页面会调用你现在的 Netlify 后台保存数据。
- 请先用新版 Netlify 包重新部署一次，否则 GitHub 页面可能因为跨域无法提交。
